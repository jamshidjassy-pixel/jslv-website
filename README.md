JSLV Website
Static, lightweight website for GitHub Pages.
Files
`index.html` — complete responsive website with embedded CSS and JavaScript
`assets/jslv-logo.png` — JSLV logo
`assets/academy-poster.png` — Academy poster
GitHub Pages
Create a GitHub repository, e.g. `jslv-website`.
Upload `index.html` and the `assets` folder.
Go to Settings → Pages.
Select `Deploy from a branch`.
Select `main` and `/root`.
Save.
Point `www.jslv.in` to the GitHub Pages URL using your domain DNS settings.
Before publishing
Replace the placeholder social-media URLs in the footer with your actual JSLV profiles.
Confirm the public email address (`info@jslv.in`) if a different address should receive enquiries.
